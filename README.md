# 🎵 CANARY Music Player

A browser-based music player built with React.js that allows users to select music files from their device and play them directly in the browser.

## ✨ Features

- ▶️ Play / Pause music
- ⏮️ Previous and Next song
- 🔀 Shuffle
- 🔁 Repeat
- 🖼️ Automatically reads embedded album artwork
- 🔍 Search songs
- 🗑️ Delete songs from the playlist
- 💿 Rotating album-disc interface
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Custom music player UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- React Router
- music-metadata-browser
- Bootstrap Icons

## 📂 How It Works

Users can select music files from their device using the file picker. The application reads the selected files in the browser and extracts available metadata such as the song name and embedded album artwork.

The selected music is played directly through the browser's audio element.
